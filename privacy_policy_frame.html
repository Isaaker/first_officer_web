4. DATA STORAGE AND BACKEND ARCHITECTURE

First Officer Bot currently operates using two separate backend systems:

  • A backend dedicated to Telegram.
  • A separate backend dedicated to Discord.

These backend systems are logically separated and maintain separate data directories for each platform.

However, both backend systems use the same underlying virtual drive storage infrastructure. The use of the same virtual drive does not mean that the Telegram and Discord backend applications share the same application directory or database namespace. Platform-specific data is maintained within the respective backend's designated directory.

Access to these storage locations is restricted to the systems and persons that require access for the operation, maintenance, security or administration of the Services.
