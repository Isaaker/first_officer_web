Aviation Command Guide

Explore all available modules and syntax for First Officer Bot.

Total Modules: 16

⭐️ General Commands

  • /start - Start using the bot
  • /commands - Friendly command guide
  • /commands_full - Full list of commands
  • /credits - Bot credits
  • /legal - Terms of Service
  • /privacy - Privacy Policy
  • /clear - Remove buttons
  • /help - Get help using the bot
  • /support - Get support
  • /version - Get current bot version and release notes
  • /feedback - Send feedback about the bot
  • /minigame - Play aviation minigame

⏰ Time

  • /zulu - Get Zulu (UTC) time
  • /time <ICAO CODE> - Get local time at airport

🌧️ Weather

  • /metar <ICAO CODE> - METAR from NOAA
  • /taf <ICAO CODE> - TAF from NOAA
  • /graphic_metar <ICAO CODE> - Shows a Graphic METAR and TAF
  • /sigmet - SIGMET information for a FIR
  • /airmet <FIR CODE> - AIRMET information for a FIR
  • /pirep <ICAO CODE> - PIREP reports for an airport
  • /pdwb - Shows Pre-Duty Weather Briefings Videos only for U.S airports

🗺️ Charts

  • /charts <AIRPORT CODE> - Airports Official Charts

✈️ ICAO & Airports

  • /icao_search <TEXT> - Search airport code
  • /icao_info <ICAO CODE> - Search about airport
  • /icao_airline_code <ICAO CODE> - Search airline data by ICAO code
  • /icao_airline_name <ICAO CODE> - Search airline data by name
  • /icao_aircraft <ICAO CODE> - Search aircraft information by ICAO code
  • /icao_aircraft_name <ICAO CODE> - Search aircraft info and ICAO code by name
  • /go_spotting - Check live airport spotting webcams

☁️ IVAO

  • /ivao_status - IVAO server status
  • /ivao_metar <ICAO CODE> - METAR from IVAO
  • /ivao_atis <ICAO CODE> - ATIS from IVAO
  • /ivao_voice_atis <ICAO CODE> - Voice ATIS from IVAO
  • /webeye - Launch IVAO WebEye in this Chat

☁️ Vatsim

  • /vatsim_status - Vatsim server status
  • /vatsim_metar <ICAO CODE> - METAR from Vatsim
  • /vatsim_flightplan <User ID> - Vatsim user flightplan

💡 Knowledge

  • /concept <CONCEPT> - Aviation concept/abbreviation info

🧮 Calculation Commands

/haversine <lat1> <lon1> <lat2> <lon2> - Distance between coordinates
/airports_haversine <ICAO1> <ICAO2> - Distance between airports
/true_airspeed <IAS> <ALT_FT> <TEMP_C> - True Airspeed
/fuel_consumption <FLOW_LPH> <HOURS> - Fuel consumption
/density_altitude <PRESS_ALT_FT> <TEMP_C> - Density altitude
/fuel_range <FUEL_L> <FLOW_LPH> <TAS_KMH> - Maximum range
/flight_time <FUEL_L> <FLOW_LPH> - Maximum flight time
/gallons_to_liters <GAL> - Gallons to liters
/liters_to_gallons <LITERS> - Liters to gallons
/kg_to_liters <KG> [<DENSITY>] - Kg to liters of fuel
/fuel_per_distance <FLOW_LPH> <TAS_KMH> - Fuel consumption per km
/knots_to_kmh <KNOTS> - Knots to kmh
/kmh_to_knots <KMH> - Kmh to knots
/knots_to_mph <KNOTS> - Knots to mph
/mph_to_knots <MPH> - Mph to knots
/ground_speed <TAS> <WIND_SPEED> <WIND_DIR> <TRACK> - Ground speed
/heading <TAS> <WIND_SPEED> <WIND_DIR> <TRACK> - Heading
/estimated_enroute_time <DIST_KM> <GS_KMH> - Estimated enroute time
/pnr <FUEL_L>... - Point of No Return (PNR)
/eqpt <DIST_KM>... - Equal Time Point (ETP)
/takeoff_distance <WEIGHT_KG>... - Takeoff distance
/landing_distance <WEIGHT_KG>... - Landing distance
/weight_and_balance <EMPTY_W_KG>... - Weight and balance

📡 Aircraft Radar

  • /flight_callsign <CALLSIGN> - Details of a flight by callsign
  • /flights_airport <ICAO or IATA CODE> - Flights near an airport (25NM)
  • /flights_registration <REGISTRATION> - Details of a flight by registration
  • /nearby_flights <LATITUDE> <LONGITUDE> - Flights near coordinates (25NM)
  • /safesky - Launch SafeSky live map in this Chat

💡 Or send your live location via Telegram directly to track flights near you! (Data is never stored).
