First Officer Bot

Welcome to First Officer Bot

Your Telegram bot companion for aviation, designed to help you with information, calculations, and more.

Go to Telegram Bot Join the Telegram Group

Features

⭐️ General Commands

  • /start - Start using the bot
  • /commands - Full list of commands
  • /credits - Bot credits
  • /legal - Terms of Service
  • /privacy - Privacy Policy
  • /clear - Remove buttons
  • /help - Get help using the bot
  • /support - Get support

⏰ Time

  • /zulu - Get Zulu (UTC) time
  • /time - Get local time at airport

🌧️ Weather

  • /vatsim_metar - METAR from Vatsim
  • /ivao_metar - METAR from IVAO
  • /metar - METAR from NOAA
  • /taf - TAF from NOAA
  • /graphic_metar - Shows a Graphic METAR and TAF

🗺️ Charts

  • /charts_general - General airport chart

✈️ ICAO & Airports

  • /icao_search - Find airport code
  • /icao_info - Info about airport
  • /icao_airline_code - Find airline data by ICAO code
  • /icao_airline_name - Find airline data by name

☁️ IVAO

  • /ivao_status - IVAO server status
  • /ivao_atis - ATIS from IVAO
  • /webeye - Launch IVAO WebEye in this Chat

☁️ Vatsim

  • /vatsim_status - Vatsim server status
  • /vatsim_metar - METAR from Vatsim
  • /vatsim_flightplan - Vatsim user flightplan

💡 Knowledge

  • /concept - Aviation concept/abbreviation info

🧮 Calculation Commands

  • /distance - Distance between airports
  • /duration - Estimated flight duration
  • /fuel - Estimated fuel needed
  • /speed - Cruise speed of the aircraft

📡 Aircraft Radar

  • /flight_callsign - Details of a flight by callsign
  • /flights_airport - Flights near an airport ICAO code (25NM)
  • /flights_registration - Details of a flight by registration
  • /nearby_flights - Flights near coordinates (25NM)

Or send your location via Telegram to see flights near you!!

🌍 SIGWX Charts

  • /spain_sigwx - Significant Weather Chart for Spain
  • /europe_sigwx - Significant Weather Chart for Europe
  • /northatlantic_sigwx - Significant Weather Chart for North Atlantic
  • /europe_south_america_sigwx - Europe & South America SIGWX
  • /europe_africa_sigwx - Europe & Africa SIGWX
  • /europe_asia_sigwx - Europe & Asia SIGWX
  • /middle_east_sigwx - Middle East SIGWX

🌧️ Winds and forecast charts

  • /wind_spain - Wind Chart for Spain
  • /surface_forecast_spain - Surface forecast Chart for Spain

🧮 Calculators

  • /cr3 - CR3 Calculator
  • /e6b - E6B Calculator
  • /cx3 - ASA CX3 Calculator
  • /calculator - Calculator App

📋 Checklists

  • /checklists - Open checklists app

🚨 NOTAMs

  • /notam - Get NOTAMs for an airport or FIR with ICAO code
